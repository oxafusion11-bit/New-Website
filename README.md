# BloodLink

BloodLink is a responsive blood donor and patient connection website.

## Features

- Search available donors by blood group, country, city, and distance.
- Shows donors in clear cards, three at a time, with pagination.
- Register as a donor or post an urgent blood request.
- Includes realistic demo data and a **Fill demo** option for presentations.
- Supports light and dark themes.
- Keeps donor contact details private while offering WhatsApp and SMS contact links.

## Run locally

Open [index.html](./index.html) in a browser, or serve the folder with any static web server:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000`.
